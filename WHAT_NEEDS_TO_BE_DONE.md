# What needs to be done

The committed team-wide source of truth for current work, owners, active agents, worktrees, and next actions is [`docs/README.md#current-register`](docs/README.md#current-register).

Before editing code, read [`AGENTS.md`](AGENTS.md), [`docs/SPEC_INDEX.md`](docs/SPEC_INDEX.md), the current register, the applicable approved spec or plan, the latest evidence, and this worktree's `HANDOFF.md` if present.
Check the worktree and coordinate ownership before changing files.

For an agent-ready handoff, ask: "Read `docs/README.md#current-register` and tell me what my workstream has completed, who owns it, and its next gated action."

`docs/08_DEMO_AND_STATUS.md` is the evidence ledger.
The relevant approved plan contains phase details and acceptance criteria.
